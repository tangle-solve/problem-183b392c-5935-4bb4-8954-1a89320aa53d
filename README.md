- **Subfield:** Convection and the hydrological cycle
- **Open:** Identify mechanisms setting MJO initiation, eastward propagation, scale, and termination. Derive observations that distinguish competing moisture, wave, and ocean-coupling theories, including Maritime Continent passage.
